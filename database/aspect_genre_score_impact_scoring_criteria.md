# 年間ジャンル別・正負分離スコアリング基準

## 1. 目的

年間ページの「恋愛」「仕事」「お金」に表示するアスペクトを、次の四要素単位で評価する。

- `T_Planet`
- `N_Planet`
- `Aspect_Angle`
- `N_House`

各ジャンルはプラス作用とマイナス作用を別々の0〜100点で持つ。混合作用は両方に点数を入れる。

同じ四要素キーは、恋愛・仕事・お金のうち必ず1ジャンルだけに分類するものではない。天体・角度・ハウスの組み合わせによって、2ジャンルまたは3ジャンルすべてへ同時に適用できる。各ジャンルの適用と点数は独立して判定し、最大スコアの1ジャンルだけへ絞り込まない。

## 2. 対象列

| ジャンル | プラス列 | マイナス列 |
| --- | --- | --- |
| 恋愛 | `Love_Positive_Impact` | `Love_Negative_Impact` |
| 仕事 | `Work_Positive_Impact` | `Work_Negative_Impact` |
| お金 | `Money_Positive_Impact` | `Money_Negative_Impact` |

旧3列（`Love_Score_Impact`、`Work_Score_Impact`、`Money_Score_Impact`）は互換用に残すが、年間3ジャンルの選定には使用しない。

## 3. 点数の意味

- プラスに働く作用はプラス列へ入れる。
- マイナスに働く作用はマイナス列へ入れる。
- 幸不幸どちらとも断定しにくく、摩擦・調整だけが残る場合はマイナス列へ弱めに入れる。
- 発展性と摩擦が併存する場合は両列へ入れる。
- 適用ジャンルで作用がない場合は `0`、非適用ジャンルは2列とも `-` とする。6列に空欄を残さない。
- 年間のジャンル適用は、代表行のジャンル別Positive／Negative列が数値かどうかで判定する。
- 対象ジャンルの2列が数値なら適用、2列とも `-` なら非適用とする。`Category` は年間3ジャンルの適用判定に使用しない。

| 点数 | 強さ |
| ---: | --- |
| 0 | 作用なし |
| 5〜25 | 弱い |
| 30〜45 | 中程度 |
| 50 | 強いが年間表示基準未満 |
| 55〜65 | 強い・年間表示対象 |
| 70〜85 | 非常に強い |
| 90〜100 | 例外的 |

## 4. 共通算定モデル

基礎強度は、現行天体のジャンル作用強度、ネイタル天体のジャンル関連倍率、ハウス倍率を掛け合わせる。

```text
基礎強度 = 現行天体強度 × ネイタル天体関連倍率 × ハウス倍率
```

角度ごとの成分係数は次のとおり。

| 角度 | プラス成分 | マイナス成分 | 扱い |
| ---: | ---: | ---: | --- |
| 0 | 天体ペアの作用方向で決定 | 天体ペアの作用方向で決定 | 結合・増幅 |
| 60 | 0.80 | 0 | 穏やかな機会 |
| 90 | 最大0.35 | 0.90 | 摩擦が主、建設的活性化を併記可 |
| 120 | 0.95 | 0 | 強い調和 |
| 150 | 最大0.20 | 0.50 | 調整・修正が主 |
| 180 | 最大0.30 | 0.85 | 対立が主、活性化を併記可 |

ハード角のプラス成分は、天体ペアがそのジャンルでプラス作用を持つ場合だけ付与する。最終値は5点刻みに丸める。

60°は機械的な高得点を避け、現行設定では最大75点とする。80点以上は発生させない。

| 4 | 1.00 | 0.80 | 0.80 |
| 5 | 1.15 | 0.75 | 0.90 |
| 6 | 0.70 | 1.15 | 0.95 |

ハウスはジャンル適用の唯一の根拠ではなく、現行天体・ネイタル天体・角度との組み合わせで評価する。

## 6. 年間表示基準

```text
表示対象 = max(プラス点, マイナス点) >= 55
```

- 強いマイナス配置も表示対象に含める。
- 件数上限は設けない。
- 同じ四要素キーが連続する期間は一つにまとめ、開始日順に表示する。
- `Yearly_Weight`、`Priority`、orb、Applying/Separatingは選定へ加算しない。
- 月間ピークルールと `Category` は、年間3ジャンルの適用判定・採点・表示判定に使用しない。

## 7. 既存試験入力の扱い

旧3列へ試験入力していた388セルは空欄化する。対象となった四要素キーは新6列で再採点し、旧符号は新しいプラス／マイナス列へ分離する。
