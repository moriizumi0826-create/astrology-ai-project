# ジャンル別アスペクト解釈文 入力ルール

## 目的

年間ページの「恋愛」「仕事」「お金」に、同じアスペクトでもジャンルに合った解釈文を表示できるようにする。

## 対象ファイル

- `M_Aspect_Interpretation jupiter,uranus.csv`
- `M_Aspect_Interpretation mercury.csv`
- `M_Aspect_Interpretation neptune,pluto.csv`
- `M_Aspect_Interpretation sun,moon.csv`
- `M_Aspect_Interpretation venus,mars.csv`

`M_Aspect_Interpretation_Yearly.csv` は対象外とする。

## 入力対象列

| 列名 | 用途 |
| --- | --- |
| `Love_Text_Description` | 恋愛・対人関係への影響 |
| `Work_Text_Description` | 仕事・役割・社会活動への影響 |
| `Money_Text_Description` | 収入・支出・資産・契約への影響 |

## 空欄と「-」の扱い

- 入力単位は「`T_Planet` × `N_Planet` × `Aspect_Angle` × `N_House`」とする。
- 同じ組み合わせにエレメントや逆行状態の異なる行が複数ある場合、その中から1行だけを入力対象の代表行にする。
- 入力対象の代表行は、文章を作成するまでは3列とも空欄にする。
- 同じ組み合わせ内の代表行以外は、3列すべてに半角の `-` を入れる。
- 空欄は「今後入力予定」、`-` は「入力しない」を意味する。両者を混同しない。
- 入力作業の完了後、対象セルに意図しない空欄が残っていないことを確認する。
- `timeline_advise` の代表行とは別の基準で管理し、その値をジャンル別3列の入力対象判定には使用しない。

## 代表行の選び方

同じ「現行天体・ネイタル天体・角度・ハウス」の中では、次の優先順位で代表行を1行選ぶ。

1. `N_Sign_Element` が `Fire`
2. `T_Retrograde_Flag` が `0`
3. `Orb_Status` が `Applying`
4. 上記を満たす行がない場合は、`Earth`、`Air`、`Water` の順で既存行を選ぶ

代表行に入力した文章は、同じ現行天体・ネイタル天体・角度・ハウスに属するエレメント違い、逆行状態違いの行でも共通して使用する。

このため、ジャンル別解釈文では代表行固有のエレメントや逆行状態を前提にせず、ハウスによる意味の違いを中心に書く。

## 解釈に使用する項目

文章は、最低限次の項目を組み合わせて作成する。

- `T_Planet`：現行天体が持ち込む作用
- `N_Planet`：影響を受ける本人の機能や欲求
- `Aspect_Angle`：作用の結びつき方や緊張の性質
- `N_House`：影響が現れやすい生活領域
- `Score_Impact`：追い風と注意傾向の方向
- 同じ組み合わせに属する各行の `Text_Description`：アスペクト本来の意味とハウス領域
- `timeline_advise`：天体と角度に共通する作用の参考情報

ハウスだけでジャンルを決めない。直接そのジャンルを示さないハウスでも、現行天体・ネイタル天体・アスペクトの組み合わせによって、恋愛・仕事・お金への影響として解釈できる。

同じ天体と角度でも、ハウスが異なる場合は別の文章を作成する。例えば1ハウスでは自己像や行動、7ハウスでは一対一の関係や契約、10ハウスでは仕事や社会的立場を中心に解釈する。

## ジャンル別の焦点

### 恋愛

- 出会い、好意、魅力、親密さ、パートナーシップを中心に書く。
- 会話、距離感、境界線、信頼、関係の進展や見直しも含める。
- 7ハウスだけでなく、5ハウスの恋愛・楽しみ、8ハウスの親密さ、4ハウスの生活基盤、11ハウスの友人関係なども、天体の組み合わせに応じて反映する。
- 恋愛関係に限定できない場合は「対人関係」「身近な相手」として表現し、交際や結婚を断定しない。

### 仕事

- 役割、評価、実務、交渉、意思決定、協力関係を中心に書く。
- 働き方、責任、情報共有、業務量、キャリア上の方向性も含める。
- 6・10ハウスだけでなく、2ハウスの能力や報酬、3ハウスの連絡、7ハウスの契約・協業、11ハウスの組織やネットワークも考慮する。
- 転職、昇進、失敗などの具体的結果を確定事項として書かない。

### お金

- 収入、支出、報酬、予算、資産、契約を中心に書く。
- 自分の価値、価格判断、共有財産、投資や大きな買い物の判断も含める。
- 2・8ハウスだけでなく、6ハウスの労働対価、7ハウスの契約、10ハウスの社会的成果、11ハウスの利益や支援も考慮する。
- 利益や損失を断定せず、判断傾向と注意点として表現する。

## 文章作成ルール

- 既存の `Text_Description` をそのまま言い換えるだけにせず、対象ジャンルでどのように現れやすいかを書く。
- 同じ行の3列は、アスペクトの核となる意味を共通させながら、具体的な影響領域をジャンルごとに変える。
- 同じ天体・角度でも、ハウスが異なる文章を流用しない。
- エレメントや逆行状態に固有の内容は書かず、同じハウス内の全バリエーションで共有できる文章にする。
- **文章構成**：原則として以下の**2文構成**とし、タイムライン上で端的に未来の展開をイメージできるようにする。
  - **1文目（どういう時期か）**：そのジャンルにおけるテーマや氣分・運気の傾向
  - **2文目（どんなことが起こりやすいか）**：具体的・実感しやすい出来事や状況の変化
- 行動アドバイス（「〜しましょう」「〜することが大切です」など）を中心にするのではなく、**「どんな出来事や変化が起こりやすいか」という直感的な描写**（「〜な場面が増えます」「〜展開が見込まれます」など）を中心に表現する。
- 文量は 1セルあたり **原則2文（80文字〜100文字程度）** を目安とし、可読性とUI表示への収まりを考慮する。
- 占星術の専門用語（「ハウス」「エレメント」「アスペクト」「ネイタル」「トランジット」「順行」「逆行」「〇度」など）や、「アスペクトを形成する」などの占星術表現は本文に使用せず、一般読者に向けた言葉に言い換える。
- 「接近中」「離脱中」「近づいている」「去りつつある」といったオーブの方向性を直接示す表現は使わず、「この時期は」「〜な傾向が高まります」など時期全体を包括する表現に統一する。
- 感嘆符「！」は使用せず、知的な美しさと品位を保った落ち着いた文章表現にする。
- `Score_Impact` が正の場合はポジティブな発展や好機、負の場合は起こりやすい摩擦や調整が必要な場面を中心に書く。
- 緊張のあるアスペクトでも不安をあおらず、起こりやすい状況と乗り越え方のニュアンスを含める。
- 調和的なアスペクトでも、必ず成功する、出会える、儲かるなどの断定表現は使わない。
- 出生図だけでは確定できない具体的な人物、金額、職種、病気、事件を作らない。
- 読者本人に向けた、自然で分かりやすい日本語にする。
- セル内改行は使用せず、1つの連続した文章として入力する。
- 既存の `Aspect_Logic_ID`、並び順、既存列の内容は変更しない。

## 避ける表現

- 「必ず」「絶対に」「確実に」などの断定
- 根拠のない結婚、別離、解雇、昇進、臨時収入、損失の予告
- 「ハウス」「アスペクト」「スクエア」「トライン」「順行」「逆行」などの専門用語、および「〜を形成する」などの占星術用語
- 「接近中」「離脱中」「近づいている」「去りつつある」などのオーブの方向性を限定する表現
- 感嘆符「！」
- 単なる行動アドバイス（「〜しましょう」「〜を心がけましょう」）に終始する表現
- どのアスペクトにも使える抽象的な文章だけで終わる表現
- 既存の `Text_Description` と意味が矛盾する文章
- ジャンル名だけを差し替えた同一文章の使い回し

## 入力例

木星 × 太陽 × 0度 × 1ハウス の解釈例（2文構成 / 80〜100文字程度）：

- **恋愛**：自信と魅力が高まり、対人関係でも新しい出会いや交流の機会が増える時期です。自分から素直にアプローチできたり、好意的な注目を集めて関係が一歩深まる展開が見込まれます。
- **仕事**：主導権を持って新しい挑戦やプロジェクトをスタートしやすい時期です。あなたの提案が通りやすくなったり、意志や実績が評価されて重要な役割を任される場面が増えます。
- **お金**：自分のスキルや価値を高めるための前向きな支出が増えやすい時期です。将来を見据えた自己投資の機会が訪れたり、新しい収入源に繋がる活動の基盤が整ってきます。

この例文は文章構造の参考であり、実際の入力では各行の天体・角度・ハウスに合わせて内容を変える。

## 入力後の確認

1. 「現行天体・ネイタル天体・角度・ハウス」の各組み合わせに、代表行が必ず1行だけあるか確認する。
2. 代表行の3列が、入力前は空欄、入力後は解釈文になっているか確認する。
3. 代表行以外の3列が、すべて `-` になっているか確認する。
4. 恋愛・仕事・お金の文章が、それぞれ異なる生活領域を説明しているか確認する。
5. ハウスが異なる行で、同じ文章をそのまま使い回していないか確認する。
6. 既存解釈、`Score_Impact`、アスペクトの性質と文章が矛盾していないか確認する。
7. 専門用語、感嘆符「！」、オーブの直接表現（接近・離脱等）が含まれていないか確認する。
8. CSVの列数、文字コード（UTF-8 with BOM）、既存の `Aspect_Logic_ID` が意図せず変更されていないか確認する。
9. 入力対象の空欄数と、完成済み文章数をファイルごとに記録する。
