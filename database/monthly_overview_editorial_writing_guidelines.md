# 月間総評CSV 執筆ガイド

対象CSV: `database/M_Monthly_Overview_Editorial.csv`

## 1. このCSVの役割

このCSVの1行は、特定の太陽星座期における、ソーラーハウスとネイタルハウスの組み合わせ専用の月間総評である。

- `Edition_ID`: 年と太陽星座期。例: `2026_CANCER`
- `Solar_House`: 太陽がその人のソーラーハウスのどこを通るか
- `Natal_House`: 同じ太陽星座期に、太陽が最も長く滞在するネイタルハウス
- 1 Edition_ID は `Solar_House 1-12 x Natal_House 1-12` の144行で構成する
- 表示時は、対象日の Edition_ID と計算済みの2ハウスで1行だけを取得する

日付の開始・終了や天体位置はCSVに保存しない。表示時に天体計算・トランジットカレンダーから決める。

## 2. 執筆時に見る情報

別メモや別ファイルは作らない。各144行を書く時は、その太陽星座期の現行天体一覧を直接確認する。

- 太陽星座期と、太陽が作るソーラーハウス上の主題
- 木星、土星、天王星、海王星、冥王星の長期配置
- 水星逆行など、期間の大部分を占める短中期要因
- 期間内の主要な星座移動・逆行開始・順行復帰
- 金星が入るソーラー／ネイタルハウスと、その期間内の星座移動

現行 x ネイタルの個別アスペクトと、現行天体同士の詳細アスペクトは、このCSVではまだ使わない。

## 3. 解釈の優先順位

本文は、次の順番で意味を組み立てる。

1. `Solar_House`: その期間に人生のどの領域が前に出るか
2. `Natal_House`: 実感、生活、行動としてどこに現れやすいか
3. 期間内の星座移動・逆行転換: 今期の流れがどこで変わるか
4. 過ごし方: 活性度と注意度を両方踏まえた現実的な力の使い方

太陽の主題を軸にする。ほかの現行天体を、全て列挙しない。本文に入れる背景は最大2つまでにする。

## 4. 個人用の長期背景は別枠にする

木星、土星、天王星、海王星、冥王星のネイタルハウスは、人ごとに異なり、太陽期の144行だけでは正確に固定できない。そのため、月間総評本文にはこれらのネイタルハウスを決め打ちで書かない。

表示時に `database/M_Personal_Long_Term_Background.csv` を照合し、総評の下へ「あなたの長期背景」として別枠で出す。

CSVの使い分けは以下とする。

- `Record_Type=background`: `Primary_Planet + Target_Sign + Target_Natal_House` で個人背景を取得する
- `Record_Type=resonance`: `Primary_Planet + Secondary_Planet + Match_Type` と、`Target_Sign` または `Target_Natal_House` で重なりを取得する
- `Active_Flag=1` の完成行だけを表示対象にする

- 個人背景: 現在の `Transit_Planet + Transit_Sign + Natal_House` が一致する行を取得する
- 表示は最大2件。土星・海王星・冥王星から負荷や再構築の要因を1件、木星から拡大や救いの要因を1件選ぶ
- 天王星は変化要因として、上位2件に入る場合だけ採用する
- ハウスを移る日には、計算結果に従って文章を正確に切り替える
- この別枠の文章を、144行の総評本文へ機械的に連結しない

さらに、トランスサタニアンと太陽・火星・木星、またはトランスサタニアン同士が重なる場合は、同CSVの `Record_Type=resonance` から最大1件を「今、強まっている重なり」として表示する。

- `same_sign`: 同じ星座にいる重なり。短期天体が長期テーマを点火する場合は最優先
- `same_natal_house`: 同じネイタルハウスにいる重なり。同じ生活領域へ複数のテーマが集まる場合に採用
- ソーラーハウスは星座から一意に決まるため、`same_sign` と重複する `same_solar_house` の別文章は作らない
- 外惑星同士だけの重なりは長期背景として扱い、短期的な出来事を断定しない

## 5. 期間内の変化の書き方

ソーラーハウスは「今期に何が前に出るか」だけでなく、期間の途中で何が切り替わるかも書く。

- `M_Transit_Calendar_<年>.csv` から、当該太陽星座期内の星座移動・逆行開始・順行復帰を確認する
- 本文には、主題を動かす変化を最大2件だけ採用する
- 金星が心身の軽さ、楽しみ、自分らしさ、人との関わりを回復させる位置へ入る場合は、上限とは別に必ず採用する
- 採用した変化は、`時期 + 天体 + 移動先の星座 + その人のソーラーハウス上の意味` を一続きで書く
- 日付が転機として重要な場合は「6月末」「7月中旬」のように時期を入れる。厳密な日付が鑑定の読みやすさを損なう場合は、日付だけを羅列しない
- 変化の前後で、何を整える時期から何を動かす時期へ移るのかを書く
- ネイタルハウスは、変化が本人の生活でどこに現れやすいかを大づかみに示す役割に留める。日ごとのネイタルハウス移動は本文へ入れない

太陽が次の星座へ移る日は次の Edition_ID の開始なので、現在のEdition本文では終盤の切り替わりとして必要な場合だけ触れる。

### 金星の扱い

金星は、重い配置の中で得られる喜び、安心、自分を心地よく扱う余裕を示す要因として毎回確認する。

- 金星がソーラー1・5・7・11ハウス、またはネイタル1・5・6ハウスに入る／滞在する場合は、本文に独立した一節を設ける
- とくにソーラー1ハウスでは、見た目、好み、日常の手入れ、自分を前向きに扱う感覚を回復要因として書く
- 全体に注意や負荷が多い Edition では、金星の小さな楽しみや軽さを「気休め」ではなく、実際に流れを支える要素として扱う

## 6. 列ごとの執筆基準

### Title

- 14-28文字を目安にする
- 今期の主題を一文で示す
- ハウス名や天体名をそのまま並べない
- 同じ Edition_ID 内で、異なる行が同じ題名にならないようにする

### Summary

- 90-150文字を目安にする
- 「何が中心か」と「どういう力の使い方が合うか」を一続きで書く
- 本文の冒頭を短縮しただけにしない

### Interpretation

- 500-900文字を目安にする
- 3-4段落で書く
- 第1段落: 今期の全体像
- 第2段落: Solar_House と Natal_House が重なる具体的な現れ方
- 第3段落: 期間内の星座移動・逆行転換が、今期の主題をどう変えるか
- 第4段落: 今期に合う過ごし方。無理に成果を急がない場合も、意味のある行動として書く
- 期間内に主題と結び付く星座移動・逆行転換がある場合は、第2段落または第3段落で1-2件を自然に織り込む
- 天体・サイン・ハウスの専門語は、本文では必要最小限にする

### Action

- 120-220文字を目安にする
- 2-3文で、今期に合う具体的な姿勢を書く
- 命令口調の箇条書きにはしない
- Interpretation の結論を、実生活の優先順位へ落とす

## 7. 文体と内容のルール

- 「必ず成功する」「病気になる」「破局する」「儲かる」と断定しない
- 不安を煽る表現にしない
- 気力低下を怠慢として扱わない
- 「運気」「エネルギー」「変化」だけで意味を済ませない。生活、仕事、対人、休息、判断など現実の現れ方を書く
- 個別アスペクトを使わない段階では、特定の出来事を予言しない
- 全144行で文章構造と語尾を機械的に繰り返さない
- `Solar_House` と `Natal_House` の役割を逆転させない
- 活性度と注意度が同居する版では、前進と休息の両方を矛盾なく書く

## 8. 144行の作業順

1. 当該太陽星座期の現行天体一覧を確認する
2. Solar_House ごとに12行をまとめて書く
3. 同じ Solar_House 内では、Natal_House 1-12 の実感差を明確にする
4. 12行書くごとに、題名・Summary・Interpretation の重複を確認する
5. 全144行を書いた後、各列の空欄、文字数、同一文を検証する

Solar_House が同じなら「人生領域の主題」は共通してよい。しかし、Natal_House が異なる12行では、生活上の実感・取り組み方・注意点を必ず変える。

## 9. 完成条件

各 Edition_ID について、以下を満たした時だけ完成とする。

- 144行がある
- `Solar_House` と `Natal_House` の全組み合わせが1回ずつある
- `Title`、`Summary`、`Interpretation`、`Action` に空欄がない
- `Interpretation` が500文字未満または900文字超過の行がない
- 同一 Edition_ID 内で Title が重複しない
- 同一 Edition_ID 内で、正規化後の Summary / Interpretation / Action が重複しない
- プレースホルダー、文字化け、未確定メモが残っていない
- 12行ずつ読み、Solar_House の主題と Natal_House の実感が正しく分かれていることを確認する
- 当該太陽星座期に主題と結び付く星座移動・逆行転換がある行は、時期と変化の意味が本文に入っている
