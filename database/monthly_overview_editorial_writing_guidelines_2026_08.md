# 2026年8月 月間総評CSV 執筆ガイド

対象CSV: `database/M_Monthly_Overview_Editorial.csv`

共通仕様は `database/monthly_overview_editorial_writing_guidelines.md` に従う。このガイドでは、2026年8月分の `Edition_ID=2026_LEO` だけを扱い、既存の別Editionを変更しない。

## 1. 固定仕様

- 2026年8月分は `Solar_House 1-12 x Natal_House 1-12` の144行
- 一度に執筆するのは、同一 `Solar_House` の `Natal_House 1-12` の12行
- 構造確定後に編集するのは `Title`、`Summary`、`Interpretation`、`Action` だけ
- `Title`: 14-28文字
- `Summary`: 90-150文字
- `Interpretation`: 500-900文字、3-4段落
- `Action`: 120-220文字、2-3文
- 完成文章へ固定日付や可変日付トークンを入れない。日付を伴う変化は可変日付段落CSVで扱う
- 個人別の外惑星ネイタルハウス解釈は長期背景CSVへ分離する

## 2. 2026年8月の基調

天体配置の正本は `database/M_Transit_Calendar_2026.csv` とする。

基調は、獅子座の太陽と木星が促す自己表現、創造性、誇り、前向きな拡張である。ただし成果や注目を断定せず、どの生活領域で自分の意志を明確にするかを `Solar_House` で具体化する。`Natal_House` は、その主題を本人が日常のどこで実感し、どのように扱うかを書き分ける。

月後半は太陽と水星が乙女座へ移るため、表現や展開から、整理、実務、調整、継続可能な形への移行を意識する。固定日付は本文へ入れず、「前半」「中盤」「後半」「月末に向けて」などで流れを書く。

## 3. 文章へ採用する変化

- 金星の天秤座入り: 関係の釣り合い、対話、美意識、心地よい距離感を回復要因として扱う
- 水星の蟹座から獅子座、乙女座への移動: 内側の検討から意思表示へ、さらに具体化と調整へ進む判断の流れとして扱う
- 火星の蟹座入り: 情報や移動へ向いていた行動力が、生活基盤、身近な人、守る範囲の整備へ移る流れとして扱う
- 太陽の乙女座入り: 月末に向けて、表現したものを実務へ落とし込む切り替わりとして必要な場合だけ触れる
- 木星の獅子座滞在: 可能性、喜び、創造性の余地として扱い、成功や利益を保証しない

1行の本文へ入れる主要変化は最大2件とし、金星の回復要因が該当する場合は別枠で自然に加える。配置を順番に列挙せず、`Solar_House` の主題を動かす時系列として統合する。

## 4. ハウスの役割

- `Solar_House`: 8月に前面へ出る人生領域
- `Natal_House`: その主題が生活上どこで実感され、判断や行動へつながるか

同一 `Solar_House` の12行では中心テーマを共有してよい。ただし、`Natal_House 1-12` では実感、具体例、活かし方、注意点を必ず変える。ハウス番号や天体名だけを差し替えた文章は完成としない。

## 5. 禁止事項

- 既存 `Edition_ID=2026_CANCER` の上書き、削除、文章変更
- 個別アスペクトや個人別外惑星ハウスの決め打ち
- 固定日付、未定義トークン、文字化け、未確定メモ
- 成功、利益、事故、破局、病気の断定
- 同一のTitle、Summary、Interpretation、Actionの完全重複
- 注意だけ、または楽観だけで文章を終えること

## 6. 12行ごとの検証

1. `Edition_ID=2026_LEO` が144行ある
2. `Solar_House x Natal_House` の重複・欠落がない
3. 執筆済み行の4文章列に空欄がない
4. 4文章列が文字数範囲内
5. 完全重複、固定日付、未定義トークン、文字化けがない
6. 条件列と既存Editionを変更していない
7. CSVをレンダリングし、文字化け、行ずれ、見切れがない
