# 2026年11月 月間基本総評 執筆ガイド

共通仕様は `monthly_overview_editorial_writing_guidelines.md`。対象は `M_Monthly_Overview_Editorial.csv` の `2026_SCORPIO`、Solar_House 1–12 × Natal_House 1–12の144行。

## 月全体の仕様

- 月初日の太陽が蠍座のため11月を通じて同じEditionを使う。22日の射手座入りでEditionを切り替えない。
- Solar_Houseは月初の蠍座が前面化する領域。Natal_Houseはその主題を本人が生活上で実感する領域で、ほかの天体のネイタルハウスではない。
- 編集列はTitle、Summary、Interpretation、Action。既存Editionと条件列を保護する。
- 一単位は同一Solar_HouseのNatal_House 1–12。各行を1人の完成した総評として読む。共通の段落順だけを品質不良と判定しない。

## 11月の暦と基調

`M_Transit_Calendar_2026.csv` を参照。日付はJSTの既存日別暦を使い、本文には月前半・中頃・月後半・月末頃の表現を使う。

| 時期 | 配置と読み方 |
|---|---|
| 前月末から前半 | 太陽・水星は蠍座、水星逆行が続く。本音、共有する条件、記録や約束を点検する。疑うこと自体を目的にしない |
| 前月末から前半 | 逆行金星は天秤座。好み、対等さ、負担配分を再確認する。復縁や交際成立を予言しない |
| 14日 | 水星は蠍座、金星は天秤座で順行へ。見直していた内容を小さく試し、合意を再確認する。即日すべて解消するとしない |
| 22日 | 太陽が射手座へ。深く確かめていた内容を、学び・見通し・外への働きかけへ広げる |
| 26日 | 火星が獅子座から乙女座へ。見せる勢いから、工程や分担を実用的に整える力へ |
| 通月 | 木星は獅子座、土星・海王星は牡羊座、天王星は双子座、冥王星は水瓶座。個人の長期背景は別枠で扱う |

基本総評は蠍座の深まりを軸に、前半の再確認から中頃以降の試行へ進む。水星と金星の順行を成果保証にしない。金星の天秤座は蠍座の一つ前のソーラーハウスであり、蠍座のSolar_Houseと混同しない。

## 文章・検証

- Title 14–28文字、Summary 90–150文字、Interpretation 500–900文字・3–4段落、Action 120–220文字・2–3文。
- 本文に採用する主な変化は最大2件。金星の回復要因は共通ガイドの条件を満たす場合、独立した一節で扱う。
- 月内の変化が本人のSolar領域で何を変えるかまで書き、天体の羅列にしない。個別アスペクトはClusterへ譲る。
- 条件列、他Edition不変、文字数、空欄、固定日付、未知トークン、文字化け、条件に対する意味の適合、重複を確認する。
- `python scripts/validate_monthly_overview_editorial.py database/M_Monthly_Overview_Editorial.csv 2026_SCORPIO`。空欄の構造行を許すvalidatorなので、完成判定は別に144行の全文章が埋まっていることも数える。
