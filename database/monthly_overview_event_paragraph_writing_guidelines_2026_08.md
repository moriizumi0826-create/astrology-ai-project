# 2026年8月 可変日付段落CSV 執筆ガイド

対象CSV: `database/M_Monthly_Overview_Event_Paragraphs_2026_08.csv`

このファイルだけを読んでも、行条件を変更せず同じ品質基準で執筆を継続できるようにする。対象は月間総評へ追加する可変日付段落だけであり、基本総評144行、スコア、長期背景、アスペクト文章は変更しない。

## 1. 固定仕様

- 総行数は840行から変更しない
- `sign_ingress` は720行
- `natal_house_ingress` は120行
- `Template_ID`、条件列、日付取得列、Priorityは変更しない
- 執筆対象は `Paragraph_Template` と `Active_Flag` だけ
- 完成段落は `{event_date}` を必ず1回以上含める
- 日付を文章へ直接書かない
- 完成・検証済みの行だけ `Active_Flag=1` にする

## 2. 2026年8月の対象イベント

### 星座移動

| 日付 | 天体 | 移動 |
|---|---|---|
| 8月7日 | 金星 | 乙女座から天秤座 |
| 8月10日 | 水星 | 蟹座から獅子座 |
| 8月11日 | 火星 | 双子座から蟹座 |
| 8月23日 | 太陽 | 獅子座から乙女座 |

日付は理解用であり、`Paragraph_Template` には書かない。表示時に `M_Transit_Calendar_2026.csv` から取得して `{event_date}` へ差し込む。

### ネイタルハウス移動を判定する星座区間

- 太陽: 獅子座、乙女座
- 水星: 蟹座、獅子座、乙女座
- 金星: 乙女座、天秤座
- 火星: 双子座、蟹座
- 木星: 獅子座

ネイタルハウス移動日は出生時刻・出生地によって異なる。文章では正確な日を決め打ちせず、移動前後の生活上の変化を書く。

## 3. 12行単位の執筆

一度に扱う単位は必ず12行とする。

### sign_ingress

同じ天体・同じ星座移動・同じソーラーハウス移動の12行を1組とし、`Natal_House_At_Event=1-12` を順に執筆する。

1組の中では、ソーラーハウスが示す「今期に前へ出る人生領域」を共通軸としてよい。ただし12行の具体的な現れ方は、ネイタルハウスに応じて必ず変える。

### natal_house_ingress

同じ天体・同じ滞在星座の12行を1組とし、隣接するネイタルハウス移動を順に執筆する。

- 12→1: 内側の整理から自己始動へ
- 1→2: 自己確立から価値・所有へ
- 2→3: 所有から情報・移動へ
- 3→4: 外との接点から生活基盤へ
- 4→5: 基盤から創造・楽しみへ
- 5→6: 表現から実務・調整へ
- 6→7: 自己管理から対人関係へ
- 7→8: 関係形成から共有・深い関与へ
- 8→9: 内部変容から展望・学びへ
- 9→10: 展望から社会的実行へ
- 10→11: 公的役割から仲間・将来計画へ
- 11→12: 外向きの活動から休息・仕込みへ

この対応表をそのまま言い換えるだけでは完成としない。天体と滞在星座の性質を加え、その月に本人が何を感じ、何を扱いやすくなるかまで書く。

## 4. 段落の内容

各段落は90-240文字を目安に、2-3文で書く。

1. `{event_date}` に何が切り替わるか
2. 生活、仕事、対人、休息、判断などにどう現れやすいか
3. 必要な場合だけ、活かし方または注意点

天体の必須観点は次の通り。

- 太陽: 月の中心、意識、自己始動、重点領域
- 水星: 判断、連絡、計画、理解、見直し
- 金星: 喜び、心身の軽さ、好み、関係、価値、金銭感覚
- 火星: 行動、負荷、競争、決断、境界
- 木星: 拡大、意味、可能性、余裕。成功を断定しない

## 5. 禁止事項

- `8月11日` など固定日付を書く
- `{event_date}` 以外の未定義トークンを作る
- 天体名、ハウス番号、星座名だけを差し替えた同一文を量産する
- 「運気が変わる」「エネルギーが高まる」だけで具体的な意味を済ませる
- 成功、病気、破局、利益を断定する
- 気力低下や休息を怠慢として扱う
- 同じ12行で題材、文順、結論をすべて同じにする

## 6. 12行ごとの検証

各組を執筆した直後に、次を確認する。

1. CSVが840行のまま
2. Template_ID重複なし
3. 条件列の変更なし
4. 完成行に空欄なし
5. 完成行に `{event_date}` がある
6. 固定日付がない
7. 完成段落の完全重複がない
8. 類似度が高すぎる段落を目視で書き分ける
9. 文字化け、改行による行ずれ、未定義トークンがない

検証コマンド:

```powershell
python scripts/validate_monthly_overview_event_templates.py database/M_Monthly_Overview_Event_Paragraphs_2026_08.csv
```
