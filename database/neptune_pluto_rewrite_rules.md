# neptune,pluto Text_Description rewrite rules draft

`M_Aspect_Interpretation neptune,pluto.csv` の `Text_Description` を作成するためのルール案です。
`venus_mars_rewrite_rules.md` を複製元としつつ、海王星・冥王星の中長期トランジットに合わせて、文体・主題・指針を調整します。

## 複製元から修正するポイント

1. **天体別トーンを全面差し替え**
   - Venus の「喜び、愛情、魅力、美的感性」は、Neptune の「理想、直感、夢、共感、境界のゆるみ、癒やし」へ置き換えます。
   - Mars の「情熱、行動力、決断力、衝動」は、Pluto の「根本変容、再生、深い執着、支配欲、手放し、底力」へ置き換えます。

2. **短期的な行動促進を弱める**
   - 金星・火星向けの「試してみたくなる」「行動へ移す」「前進する」だけでは、海王星・冥王星には軽すぎます。
   - 海王星では「内側の声を聴く」「曖昧さを言語化する」「境界を整える」方向へ寄せます。
   - 冥王星では「本質を見抜く」「握りしめているものを手放す」「力の使い方を見直す」方向へ寄せます。

3. **注意喚起の質を変更**
   - 海王星は、混乱・理想化・自己犠牲・境界の曖昧さを、怖がらせずに扱います。
   - 冥王星は、執着・極端さ・支配欲・破壊衝動を、悪いものとして断罪せず、再生力や集中力へ変換する形で扱います。

4. **逆行フラグの意味を中長期向けに変更**
   - Neptune 逆行 (1): 理想、信念、憧れ、思い込み、救済願望の再検討。外へ広げるより、内側で見直す時期として扱います。
   - Pluto 逆行 (1): 執着、力関係、過去の傷、支配と依存、深い変容課題の再浮上。外側を変えようとするより、内面の根を掘り下げる時期として扱います。

5. **文体を「ワクワク」一辺倒にしない**
   - `0`、`60`、`120` は前向きな期待感を入れますが、木星・天王星のような高揚感ではなく、静かな確信・深い癒やし・再生の手応えを中心にします。
   - `90`、`150`、`180` は警告で終わらせず、混乱や圧力を通じて、本質的な整え直しが進む流れとして書きます。

6. **CSVの実態に合わせる**
   - 対象CSVは `Text_Description` が全行空欄です。
   - `Orb_Status` は現状 `Applying` のみですが、本文では「接近中」「ピーク前」などの語を使わず、将来 `Separating` が混ざっても使える包括表現にします。
   - 対象は `TRANSIT_NEPTUNE` と `TRANSIT_PLUTO`、ネイタル側は太陽・月・水星・金星・火星・木星・土星・天王星・海王星・冥王星・ASC・MCです。

## 基本方針

1. `Text_Description` では、接近中・離脱中・ピーク前・ピーク後を示す言葉は使用しないでください。
   - 禁止例: 接近中、離脱中、近づいている、過ぎたあと、ピークに向かう、ピークを越える
   - 使用例: この時期は、今は、こうした流れの中で、しばらくの間

2. 角度の説明は本文に入れないでください。
   - 見出しに天体と角度が表示されるため、本文では「0度」「60度」「90度」などを書かないでください。
   - 「形成」という言葉も使用しないでください。

3. 専門用語は本文に出さないでください。
   - 禁止例: ハウス、エレメント、アスペクト、ネイタル、トランジット、火、地、風、水、順行、逆行
   - 代わりに、読者が体感として理解できる言葉へ置き換えてください。

4. 文章の流れは、原則として以下の順にしてください。
   - どういう影響を及ぼす時期なのか
   - 起こりやすい状況、精神状態、対人関係や生活上の傾向
   - その時期の意識指針

5. 文量は3文から5文を基本にしてください。
   - 1文目: 時期全体の影響
   - 2文目: 具体的に起こりやすい状況
   - 3文目: 心身や関係性の傾向
   - 4文目以降: 意識指針

6. 末尾の指針は、具体的な作業指示よりも「意識の置きどころ」「選び方の軸」「受け止め方」に寄せてください。
   - 避けたい例: 今日から着手できる一歩を決める、予定に入れる、実際に行動へ移す、作業を進める
   - Neptune 推奨例: 理想を急いで形にしようとするより、心の奥で何に救いや希望を感じているのかを丁寧に見つめる
   - Neptune 推奨例: 相手の感情をすべて引き受けるより、自分を守るためのやさしい境界線を意識する
   - Pluto 推奨例: 状況を力で動かそうとするより、なぜそれを失うことが怖いのかを静かに掘り下げる
   - Pluto 推奨例: 終わらせることを敗北と捉えず、次の再生のために必要な余白として受け入れる

7. 表現や末尾の締め方がワンパターンにならないようにしてください。
   - 同じ語尾や構文を連続して使いすぎないでください。
   - 特に「〜しやすくなります」「〜につなげやすくなります」「〜が大切です」だけで締め続けないでください。
   - 末尾は、行ごとの天体・角度・領域に合わせて変化をつけてください。
   - 締め方の例: 「〜を意識するほど、曖昧だった願いに静かな輪郭が戻ってきます」「〜を受け入れると、深いところから再生の力が動き出します」「〜を見極めることが、この時期の変化を穏やかに扱う鍵になります」

8. 角度によって、期待感や再生後の手応えを入れてください。
   - `0`、`60`、`120` では、「内側の声が澄んでくる」「深い癒やしが進む」「本質的な力が目覚める」「静かな確信が育つ」などの表現を入れてください。
   - `90`、`150`、`180` では、単なる注意喚起で終わらせず、「境界を整えるきっかけになる」「執着の奥にある本音に気づく」「力の使い方を見直すことで関係性が変わる」など、改善後の見通しを入れてください。
   - ただし、「必ず救われる」「完全に生まれ変わる」などの過剰な断定は避けてください。

9. 運気の働きと直接つながらない一般的な注意文は入れないでください。
   - 禁止例: 無理をすると体調を崩す、焦ると失敗しやすい、早寝早起きをする
   - 疲れや混乱、対人摩擦に触れる場合は、海王星の境界の曖昧さ、冥王星の圧力や執着、角度、生活領域から明確に説明できる場合に限定してください。

10. 機械的な一括生成や連続した自動生成は厳禁とし、1行ずつ完全に独立した固有の文章を丁寧に作成してください。
    - テンプレートの変形や、他行の文章の一部を書き換えただけの類似した文章を乱発することは避けてください。
    - 1行ごとに天体・角度・生活領域・属性・逆行フラグの象意を個別に吟味し、それぞれが固有のメッセージを持つ文章として作成してください。
    - `Text_Description` は全行で完全にユニークにしてください。同一CSV内で、別行と一字一句同じ文章を作成することは禁止です。
    - 同じ天体・生活領域・属性・逆行フラグでも、角度が異なる場合は必ず角度ごとの体感、課題、指針を変え、完全一致しない文章にしてください。
    - `Text_Description` が2000行埋まるごとに完全一致チェックを行い、非空欄の重複が1件でもあれば、その時点で修正してください。

## 天体別トーン

### Transit Neptune

海王星では、「理想、夢、直感、共感、癒やし、想像力、境界の曖昧さ、自己犠牲、現実感の揺らぎ」を扱ってください。

- 主題: 何に救いや希望を感じるか、理想と現実の距離、共感や感受性、見えない不安や憧れ
- 体感: 直感が冴える、夢や想像が広がる、境界が曖昧になる、相手の感情に同調しやすい、判断がぼやける
- 指針: 理想を言語化する、境界線をやさしく整える、曖昧さを急いで結論づけない、感性を現実の形へ少しずつ落とし込む

文体では、幻想的にしすぎず、やわらかさ・静けさ・透明感・現実へ戻る視点が伝わるようにしてください。

### Transit Pluto

冥王星では、「根本変容、再生、終わりと始まり、執着、支配欲、深層心理、極限、底力、影響力」を扱ってください。

- 主題: 何を根本から変える必要があるか、何を握りしめているか、力関係や深い結びつき、再生のための手放し
- 体感: 圧力が強まる、深い本音が浮上する、極端になりやすい、支配と依存が見えやすい、集中力や底力が湧く
- 指針: 本質を見抜く、力で押し切らない、終わらせるべきものを認める、執着の奥にある恐れや願いを扱う

文体では、重さだけでなく、深いところから立て直される感覚、静かな強さ、再生の可能性が伝わるようにしてください。

## 角度別ニュアンス

### 0

トーン: 強く重なる、境界が溶ける、深い始まり、自己同化

- Neptune: 理想や直感がその人の中心に強く入り込み、夢や感性が生き方を動かす流れとして扱ってください。現実感が薄れすぎる危うさにも触れつつ、曖昧な願いに輪郭を与える方向で書いてください。
- Pluto: 深層の力や変容欲求がその人の中心に強く入り込み、人生の根本的な作り替えが始まる流れとして扱ってください。支配や極端さを煽らず、再生のために本質を見抜く方向で書いてください。
- 期待感: 内側から新しい感覚が目覚める、避けてきた本音に気づく、静かだが大きな切り替わりが始まる感覚を入れてください。

- Pluto: 深い洞察や集中力を、現実的な改善に活かしやすい流れとして扱ってください。小さな手放しや率直な見直しが、再生のきっかけになる方向で書いてください。
- 期待感: 静かな気づきが思った以上に大きな整え直しを生む感覚を入れてください。

### 90

トーン: 違和感、混乱、圧力、見直しを促す摩擦

### 120

### 150

トーン: 微調整、違和感、噛み合わなさ、無意識の修正

- Neptune: 理想や共感の向け方が、日常の現実や相手の事情と微妙に噛み合いにくい流れとして扱ってください。曖昧なまま流されず、言葉・距離感・生活習慣を細かく整える方向で書いてください。
- Pluto: 深い欲求や執着が、日常のペースや周囲との関係に微妙な負荷をかけやすい流れとして扱ってください。力の入れどころを修正し、不要なこだわりを少しずつ緩める方向で書いてください。
- 期待感: 細かな違和感を放置せず整えることで、深い変化を穏やかに扱える感覚を入れてください。

### 180

- 誇張しすぎず、実際の体感や生活上の場面に落ちている
