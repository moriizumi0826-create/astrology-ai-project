# Text_Description cleanup rules

このメモは、`M_Aspect_Interpretation *.csv` の `Text_Description` を整えるときの削除・補正ルールです。
sun/moon 以外の mars などのファイルにも、同じ考え方で適用します。

## 最優先ルール

- ユーザーが「文字列だけ削除」と言った場合は、その文字列だけを削除する。
- ユーザーが「句ごと削除」と言った場合だけ、次の読点 `、` までを含めて削除する。
- 読点が後ろまでなく、句だけ削ると本文が不自然になる場合は保留する。
- `Text_Description` 以外の列は変更しない。
- 行全体を削除しない。
- 空欄にする指示がある場合だけ、`Text_Description` を空欄にする。勝手に `-` は入れない。
- 本文の再生成や言い換えは、明示指示がない限り行わない。

## 冒頭の専門用語削除

### 文字列だけ削除するもの

以下で始まる場合は、冒頭の指定文字列だけ削除する。

- `MCと`
- `アセンダントと`
- `ASCと`

例:

- `MCと自分の信念や理想に対する感受性が強まり、...`
- 削除後: `自分の信念や理想に対する感受性が強まり、...`

### 複合語として削除するもの

以下で始まる場合は、指定された複合語全体だけ削除する。

- `MCとトランジットの月が`
- `アセンダントとトランジットの月が`
- `ASCとトランジットの月が`

注意:

- `MCとトランジットの月が` に対して `MCと` だけを削除して、`トランジットの月が...` を残さない。
- `アセンダントとトランジットの月が` も同様。

## 句ごと削除する残りかす

以下のような、前半が欠けていて単独では意味をなさない句は、句ごと削除する。
次の読点 `、` までを含めて削除する。

- `で重なり、`
- `で向き合い、`
- `で向き合って、`
- `で向き合うことで、`
- `で近づき、`
- `で響き、`
- `で調和し、`
- `で連携し、`
- `でぶつかり、`
- `で衝突し、`
- `で葛藤し、`
- `で葛藤し合い、`
- `で刺激し合い、`
- `で支え合い、`
- `で補い合い、`
- `で噛み合いにくく、`
- `で噛み合わず、`
- `で嚙み合わず、`
- `でかみ合わず、`
- `で真正面から向き合い、`
- `と形成し、`
- `の〇〇の角度を取り、`

表記ゆれ:

- `噛` と `嚙` は両方見る。
- `噛み合わず`、`嚙み合わず`、`かみ合わず` を見る。
- `噛み合いにくく`、`嚙み合いにくく`、`かみ合いにくく` を見る。

## 句ごと削除してよい専門用語句

以下のように、冒頭の短い句が専門用語だけで構成されており、削除後の文が自然に続く場合は句ごと削除してよい。

- `ネイタル...が重なり、`
- `トランジット...が重なり、`
- `ネイタル...とトランジット...が重なり、`
- `ネイタル...とトランジット...で重なり、`
- `ネイタル...とトランジット...で向き合い、`
- `ネイタル...とトランジット...で葛藤し合い、`
- `ネイタル...とトランジット...で調和し、`
- `ネイタル...とトランジット...で連携し、`
- `ネイタル...とトランジット...で響き、`
- `ネイタル...とトランジット...が向き合い、`
- `ネイタル...とトランジット...が葛藤し合い、`
- `ネイタル...とトランジット...が調和し、`
- `ネイタル...とトランジット...が連携し、`
- `ネイタル...とトランジット...が響き、`
- `トランジットの月がMCと重なり、`
- `トランジットの月がアセンダントに重なり、`
- `...角度...、`

ただし、読点までが長く、意味を持つ本文になっている場合は削除しない。

保留例:

- `MCと自分の情熱が社会的なチャンスとスムーズに連携し、...`
- `アセンダントと自分の居場所や基盤を自分らしく整えたい欲求が前向きに高まり、...`

この場合は、`MCと` や `アセンダントと` だけを削除すれば自然になるなら、文字列だけ削除する。

## 4エレメント同一本文の削除

同じ条件で `N_Sign_Element` だけが `Fire` / `Earth` / `Air` / `Water` と異なる4行があり、4行の `Text_Description` が完全一致している場合は、4行すべての `Text_Description` を空欄にする。

判定キーの基本:

- `T_Planet`
- `N_Planet`
- `Aspect_Angle`
- `Category`
- `N_House`
- `T_Retrograde_Flag`
- `Orb_Status`
- `Countdown_ID`
- `Impact_Type`
- `timeline_Label`

注意:

- `Aspect_Logic_ID` はこの判定には使わない。
- 行は削除しない。
- 他列は変更しない。

## 150文字以下の本文

ユーザーから明示された場合のみ、`Text_Description` の総文字数が150文字以下のものを削除対象にする。
この条件は常時適用しない。

## 末尾が中途半端な文の補完

`。` で終わっていても、文として未完了なら補完する。
削除ではなく、意味を大きく変えずに自然な終止形へ直す。

検出対象の例:

- `無駄を省き。`
- `実務的な学びを深め。`
- `理想を高く掲げ。`
- `今は大きな決断を避け。`
- `感情的な充足を大切にしつつ。`
- `内面的な成長を促すような体験や。`
- `対話を通じて自分の魅力が伝わりやすく。`
- `自分の不安を家族にぶつけるのではなく。`

補完方針:

- ます形の語幹で止まっている場合: `深め。` → `深めます。`
- `避け。` / `控え。` / `心がけ。` などの場合: `避けることが大切です。`
- `や。` で終わる場合: `などが意識に上りやすくなります。`
- `しつつ。` / `つつ。` / `ながら。` の場合: `、無理のない姿勢を意識することが大切です。`
- `ではなく。` の場合: `、自分の感覚を丁寧に見直すことが大切です。`
- `やすく。` の場合: `やすくなります。`
- 句点なしで終わる場合も、同じく自然な終止形に補完する。

注意:

- 雑に全文再生成しない。
- 末尾だけを補完して自然にする。
- 補完ログを残す。
- 補完後に再スキャンし、末尾未完了候補が0件になっていることを確認する。

## 不自然な英語残りの処理

`Text_Description` 内に不自然な英語が残っていないか確認する。

削除または補正対象:

- `of`
- `the`
- `the of`
- その他、日本語文中に混ざった意味不明な英単語

例:

- `真実 of 潤いと` → `真実の潤いをもたらします。`
- `恋愛や趣味 of 場` → `恋愛や趣味の場`

許容する英語:

- `SNS`
- `AI`
- `IT`

注意:

- `SNS` / `AI` / `IT` は自然な表現なので残す。
- 英語部分を削除するだけで文章が不自然になる場合は、前後を最小限補正して自然な日本語にする。
- 補正後に、許容語以外の英語が残っていないことを再スキャンする。

## 実行前後の確認

実行前:

- 対象件数を出す。
- 削除・補正前後のサンプルを数件出す。
- 「文字列だけ削除」か「句ごと削除」かを明確にする。

実行後:

- 変更件数を出す。
- 対象文字列や未完了文が残っていないことを確認する。
- `Text_Description` 以外の列を変更していないことを確認する。
- `-` を勝手に入れていないことを確認する。
- 変更ログやバックアップを作った場合はファイル名を報告する。
