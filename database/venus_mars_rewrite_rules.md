# venus,mars Text_Description rewrite rules draft

`M_Aspect_Interpretation venus,mars.csv` の `Text_Description` を、接近中・離脱中のどちらにも使える本文へ書き換えるためのルール案です。

## 基本方針

1. `Text_Description` では、接近中・離脱中・ピーク前・ピーク後を示す言葉は使用しないでください。
   - 禁止例: 接近中、離脱中、近づいている、過ぎたあと、ピークに向かう、ピークを越える
   - 使用例: この時期は、今は、ここでは、こうした流れの中で

2. 角度の説明は本文に入れないでください。
   - 見出しに天体と角度が表示されるため、本文では「0度」「60度」「90度」などを書かないようにしてください。
   - 「形成」という言葉も使用しないでください。

3. 専門用語は本文に出さないでください。
   - 禁止例: ハウス、エレメント、アスペクト、ネイタル、トランジット、火、地、風、水
   - 代わりに、読者が体感として理解できる言葉へ置き換えてください。

4. 文章の流れは、原則として以下の順にしてください。
   - どういう影響を及ぼす時期なのか
   - 起こりやすい状況、精神状態、体調や対人関係の傾向
   - その時期の意識指針

5. 文量は3文から5文を基本にしてください。
   - 1文目: 時期全体の影響
   - 2文目: 具体的に起こりやすい状況
   - 3文目: 心身や関係性の傾向
   - 4文目以降: 意識指針

6. 末尾の指針は、具体的な作業指示よりも「意識の置きどころ」「選び方の軸」「受け止め方」に寄せてください。
   - 避けたい例: 今日から着手できる一歩を決める、予定に入れる、実際に行動へ移す、作業を進める
   - 推奨例: 周囲にどう見られるかよりも、自分が何に喜びを感じるかを見つめる
   - 推奨例: 焦って行動を急ぐよりも、自らの情熱が本当に向かっている先を静かに見極める
   - 推奨例: 相手に合わせきるよりも、お互いが心地よく向き合える距離感を意識する
   - ただし、本文全体が抽象的になりすぎないよう、起こりやすい状況や体感は具体的に書いてください。

7. 表現や末尾の締め方がワンパターンにならないようにしてください。
   - 同じ語尾や構文を連続して使いすぎないでください。
   - 特に「〜しやすくなります」「〜につなげやすくなります」「〜が大切です」だけで締め続けないでください。
   - 末尾は、行ごとの天体・角度・領域に合わせて変化をつけてください。
   - 締め方の例: 「〜を意識することで、関係性の質が豊かに整っていきます」「〜を見出すほど、心地よく進む感覚が育ちます」「〜にエネルギーを注ぐことが、この時期の展開を動かす鍵になります」「〜を受け入れると、自然と次のステップが見えてきます」
   - 断定が強すぎる表現や、毎回同じ励まし方になる表現は避けてください。

8. 角度によっては、やる気や期待感が高まるニュアンスを積極的に入れてください。
   - 特に `0`、`60`、`120` では、「楽しみになる」「試してみたくなる」「魅力が引き出される」「前向きな手応えがある」「次の展開が見えてくる」など、読者の行動意欲や喜びが上がる表現を入れてください。
   - `90`、`150`、`180` では、単なる注意喚起や衝突の警告で終わらせず、「ここを整えると関係性が良くなる」「エネルギーの方向を見直すことで突破口になる」「心地よさを追求し直すきっかけになる」など、改善後の期待感を入れてください。
   - ただし、「必ず成功する」「最高の関係になる」などの過剰な断定は避けてください。

9. 運気の働きと直接つながらない一般的な注意文は入れないでください。
   - 禁止例: 勢いだけで予定を広げると疲れる、無理をすると体調を崩す、焦ると失敗しやすい
   - 疲れや焦り、摩擦などに触れる場合は、その行の天体（特に火星）やアスペクト角度、ハウス（実務や健康の6、休息や内面の12）から明確に説明できる場合に限定してください。
   - 金星の本文では、喜び、調和、感性をテーマとし、単なる健康管理のアドバイスなどは避けてください。火星の本文では、情熱の暴走や焦りに対して、エネルギーの創造的な使い方を指針として提示してください。

10. 機械的な一括生成や連続した自動生成は厳禁とし、1行ずつ完全に独立した固有の文章を丁寧に作成してください。
    - テンプレートの変形や、他行の文章の一部を書き換えただけの類似した文章を乱発することは絶対に避けてください。
    - 1行ごとに天体・角度・ハウス・エレメント・逆行フラグの象意を個別に深く吟味し、それぞれが固有のメッセージを持つ独立した独自の文章として丁寧に作成してください。

## 天体別トーン

### Transit Venus

金星では、「喜び、楽しさ、愛情関係、魅力、美的感性、社交、価値観」を扱ってください。

- 主題: 何に心地よさや愛着を感じるか、人間関係での調和、美やセンスの表現
- 体感: 楽しむ意欲、リラックス、人との調成、喜びやセンスの開花、受け入れる姿勢
- 指針: 楽しさを優先する、人との関わりを円滑にする、感性を満たす、魅力を表現する

文体では、華やかさや温かさ、調和と喜びが伝わるようにしてください。

### Transit Mars

火星では、「情熱、行動力、決断力、衝動、自己主張、挑戦、エネルギー」を扱ってください。

- 主題: どこにエネルギーを注ぐか、自己主張や境界線の確立、困難への挑戦
- 体感: 意欲の高まり、行動への衝動、スピード感、摩擦や焦燥感、やり抜く力
- 指針: 情熱を行動に移す、境界線をはっきりさせる、自律的に動く、摩擦をモチベーションに変える

文体では、力強さや前向きな推進力が伝わるようにしてください。怒りや対立を単に恐れるのではなく、それを突破口にする姿勢を示してください。

## 角度別ニュアンス

### 0

トーン: 強く重なる、目立つ、始まり、自己一致

- Venus: 自分の魅力や感性が前面に出る流れとして扱ってください。新しい愛着の始まり、センスの表現、人間関係の新鮮なスタートを強める方向で書いてください。
- Mars: 強い情熱や行動力が前面に出る流れとして扱ってください。新しい挑戦、自発的な行動開始、自己主張を強める方向で書いてください。
- 期待感: 魅力が輝き出す感覚、新たな熱意が湧き上がる高揚感、新しい一歩を勢いよく踏み出したくなる期待感を入れてください。
- 表現例: 魅力がはっきり浮かび上がる、情熱が強く意識しやすい、新しく切り替わりやすい、試してみたくなる、始まりの手応えがある

### 60

トーン: 小さな好機、自然な協力、扱いやすい流れ

- Venus: 人間関係の調和や趣味の機会を無理なく活かしやすい流れとして扱ってください。周囲との心地よい会話や小さなセンスの表現が関係構築につながる方向で書いてください。
- Mars: 行動意欲を具体的なアクションにスムーズに移しやすい流れとして扱ってください。周囲との軽い連携や小さな工夫が前進につながる方向で書いてください。
- 期待感: 軽い提案や試みが思った以上に良い展開や喜びを生む期待感を入れてください。
- 表現例: 無理なく進めやすい、きっかけを掴みやすい、自然と調和しやすい、試してみたくなる、心地よい手応えを感じやすい

### 90

トーン: 違和感、摩擦、調整、行動を促す圧力

- Venus: 社交上の違和感、感情的な葛藤、楽しさの追求での過剰さやズレが出やすい流れとして扱ってください。対人関係や価値観のバランスを調整する方向で書いてください。
- Mars: 焦りや怒りの衝動、他者との摩擦が表面化しやすい流れとして扱ってください。その葛藤をエネルギーの方向性の見直しや、限界突破へのモチベーションに変える方向で書いてください。
- 期待感: 違和感や摩擦と向き合うことで、関係性や行動の質が劇的に改善する突破口の期待感を入れてください。
- 表現例: すれ違いやすい、焦りが出やすい、摩擦が生じやすい、調整が必要になる、突破口を見つけやすい

### 120

トーン: 安定した追い風、自然な発展、才能の使いやすさ

- Venus: 自分の魅力や愛着を自然に表現し、受け入れられやすい流れとして扱ってください。心地よい人間関係や感性の発展を安心して楽しめる方向で書いてください。
- Mars: 目的の遂行や行動の持続が非常にスムーズな流れとして扱ってください。実力を遺憾なく発揮し、前向きな成果へと繋げやすい方向で書いてください。
- 期待感: 今ある魅力や実力を使うほどに、関係性が深まり活動の可能性が広がる高揚感を入れてください。
- 表現例: 自然に流れが整う、無理なく力を発揮できる、心地よい調和に満ちる、前向きな展開が見えてくる

### 150

トーン: 微調整、違和感、噛み合わなさ、習慣の修正

- Venus: 人との距離感や趣味の好みが周りと微妙に噛み合いにくい流れとして扱ってください。相手のペースや環境に合わせて、楽しむ姿勢や付き合い方を微調整する方向で書いてください。
- Mars: 行動のペース配分やエネルギーの使い方が噛み合いにくい流れとして扱ってください。無理な力押しを避け、効率的な手順や体調の調整を図る方向で書いてください。
- 期待感: 細かな微調整を行うことで、関係性や行動のクオリティがより快適に整う期待感を入れてください。
- 表現例: 微妙なズレが出やすい、無理をすると乱れやすい、細かな調整が必要になる、整えるほど動きやすくなる

### 180

トーン: 対面、他者からの刺激、客観視、バランスの取り直し

- Venus: 他者からの強い好意や要望に向き合う流れとして扱ってください。相手の反応を通じて、自分の対人姿勢や価値観のバランスを整える方向で書いてください。
- Mars: 他者との衝突や競合、強い交渉ごとが起こりやすい流れとして扱ってください。妥協するのではなく、お互いの意志をぶつけ合いながらも健全な協力関係や適度な距離感を確立する方向で書いてください。
- 期待感: 他者との深い関わりや交渉を通し、お互いの関係性をより建設的で確固たるものへ引き上げる期待感を入れてください。
- 表現例: 向き合う場面が増える、外からの反応で気づく、バランスを取り直す必要がある、関係性をより強固にするきっかけになる

- Earth: 現実性、安定、身体感覚、実務、積み重ね

## T_Retrograde_Flag の反映方針

金星と火星は逆行が発生するため、逆行中のニュアンスを以下のように反映してください。

- Venus 逆行 (1): 人間関係の再評価、過去の愛着や趣味の再燃、価値観の見直し。懐かしい出会いや、過去のセンスの再発見を促す方向で書いてください。
- Mars 逆行 (1): 行動の一時的なペースダウン、情熱を注ぐ対象の内省、過去のやり残した挑戦やプロジェクトの再開。焦って進めるより、足元を固め直す方向で書いてください。
- Retrograde 0 の場合: 通常通り、スムーズな前進や自然な表現として扱ってください。

## 品質チェック

書き換え後に以下を確認してください。

- `形成` が含まれていない
- `接近中` が含まれていない
- `離脱中` が含まれていない
- 角度の数値説明が本文に含まれていない
- ハウス、エレメント、アスペクトなどの専門用語が本文に含まれていない
- 影響だけで終わらず、意識の置きどころや選び方の軸が入っている
- 角度に応じて、やる気や期待感、または改善後の前向きな展開が入っている
- 運気の働きと直接関係しない一般的な注意文が入っていない
- 誇張しすぎず、実際の行動や体感に落ちている
- 表現や末尾の締め方が同じ型に偏っていない
- 金星逆行・火星逆行時の「見直し・過去・内省」のニュアンスが適切に反映されている
