# 望みと資質の照らし合わせ：テスト版

独立ページ `frontend/alignment.html`。ログインなしで固定8問 → 出生情報 → 回答別の追加2問 → 仮まとめ → 項目別の反応・補足 → 更新履歴を利用する。

## 現在使える部分

- 既存 Swiss Ephemeris の出生図計算を `POST /api/alignment/chart` から呼ぶ。氏名不要、回答・自由記述は送らない。ファイル・DB・AIには保存しない。
- 10天体・Placidusハウス・伝統的支配星・アスペクト・オーブを返す。元の計算モジュールは変更しない。
- 時刻不明は現地正午の概算。ハウス・ASC・MC・月アスペクトは不使用。タイムゾーンは出生地の歴史的オフセットを採用し、重複時刻にはfold指定が必要。
- 出生地検索は既存 `/api/location-search`。検索時は場所名だけ送信。候補選択後の座標・タイムゾーンは画面で確認でき、直接入力も可能。
- 計算失敗は表示し、再試行または出生図なしで継続可能。計算していない配置を補わない。
- 質問と仮まとめは `alignment-session.mjs` のルール。未知・未回答を否定扱いせず、単一の乖離率・金運スコアは出さない。
- 「少し違う」「条件による」は対象の仮説を保留にし、本人の原文を添える。AIで再解釈したとは表示しない。元のまとめは直近20件、補足は最大50件。
- 明示操作だけでブラウザ保存、削除、JSON書き出し・読込。自動保存・クラウド保存なし。読み込みは値の種類・選択肢・長さを制限。保存された出生図は最新の計算結果として信用せず、再計算を求める。

## ローカル起動

1. リポジトリルートで `python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8104 --no-access-log`
2. frontendで `npm run dev -- --host 127.0.0.1 --port 5185 --strictPort`
3. `http://127.0.0.1:5185/alignment.html`

Vite開発サーバーはこの機能の2つのAPIを8104へプロキシする。既存の他画面のAPI先は変えない。配備ビルドでは既存の `VITE_API_BASE_URL` を使用。静的GitHub Pagesだけでは出生図のAPIは動かないため、このバックエンドも更新する必要がある。未配備の場合も回答だけの体験は利用可能。

## 最後に接続する部分

AIの質問生成・自由記述の意味の解釈・出生図を用いた文章化・補足による再解釈は未接続。APIキーはフロントへ渡さない。接続時はサーバー側に専用エンドポイントを追加し、以下を構造化して受け渡す。

- 固定質問のバージョン、回答ID、補足原文、自由質問IDと回答。
- サーバーが出生情報から再計算した出生図。ブラウザや保存JSONから送られた天体配置を信用しない。
- 各項目の本文、根拠の質問ID・配置ID、不確かさ、維持・修正・未判断の変更理由。
- 自由質問は1〜3問、入力長・呼出回数・匿名利用の上限とタイムアウトをサーバーで制限。
- 本人の訂正を「抵抗」と扱って元の見立てを守らない。AIが生成した配置は、計算済みの事実と照合して採用する。

APIキーを入れるだけで現行ルールがAIへ自動的に切り替わる実装ではない。AI接続はこの境界に追加する。質問文・照合ルールの最終調整と実際のユーザーテストも残る。
