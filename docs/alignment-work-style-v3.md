# 24問で見る働き方と仕事の例

## 体験

24問の選択式回答 → 必須の出生情報 → Lv.99までの一致度、回答と出生図の2列のカード、仕事の例4件を即時表示。
結果を見るまでにAIや自由記述の回答を要求しない。
結果から任意でAIの自由質問へ進め、本人の補足から文章の見立てを更新できる。
AIに接続できない場合も、即時結果は残る。

## 設問

原本は `database/alignment_work_style_v3.json`。フロントとサーバーで同じID・文面・選択肢を使用する。
専門性・探究／改善・継続／企画・推進／創作・発信／対話・支援／管理・調整／協働・つながりの7項目を各3問で確認。
各項目は、関心を聞く1問、別の方向から続けやすさを聞く逆転項目1問、実経験を聞く1問。
残り3問は望む稼ぎ方・大切な条件・進め方。

4件法を100・66.67・33.33・0点へ換算し、逆転項目では反転する。
「まだわからない・未経験」は0点にしない。既知の項目だけを平均する。
これは独自の探索用質問であり、MBTIや統計的に検証された心理検査ではない。

## スコア

- 左は回答だけの7項目、右は出生図だけの7項目。混合平均を廃止する。
- 各項目で回答が3問とも未確認の場合、左は未確認のままにする。右の値で埋めない。
- 出生図は2・6・10ハウス支配星の所在、2ハウスの在室天体、水星・金星の所在を使用。
- 使用するハウス別対応表は `backend/app/services/alignment_work_style.py` の `HOUSE_POINTS`。
- 円形ゲージは両者の一致度ひとつ。`Lv＝四捨五入（99×（1−各項目の絶対点差の平均÷100））`。範囲はLv.0〜99。
- 項目別に比較し、総平均同士は比べない。逆方向の傾向が平均によって相殺されることを防ぐ。
- 左の値が未確認の項目は一致度から除く。比較数が7未満なら画面に件数を示す。全項目未確認ではゲージは「—」とし、回答カード・出生図カード・仕事例はそのまま表示する。
- 両側とも棒グラフは0〜100で固定し、同じ項目・同じ順序で表示。左右をそれぞれ順位で並べ替えない。
- 左はセージグリーン、右は落ち着いたゴールド。左右には円形ゲージを置かない。
- タイプ名は両側それぞれの上位2項目から42種類を選び、「集中型・複合型・バランス型」の3特徴を添える（126の表示パターン）。原本は `alignment_comparison.py`。
- 全既知項目の最高値−最低値が12以下ならバランス型。それ以外で1位−2位が18以上なら集中型。それ以外は複合型。同点は設問定義順で安定分類。
- 左で既知の項目が2未満、または最高値が25未満の場合は探索中のラベルにする。出生図側の分類に左の回答を使わず、回答側の分類に出生図を使わない。
- 大切な条件と進め方は提案の条件に使い、能力点へ混ぜない。
- スコアと仕事例は固定処理で決まり、同じ回答・出生図なら同じ結果になる。

一致度は左右のプロフィールの近さであり、資質の活用度や実績の測定ではない。現在の設問には関心・希望も含まれるため、実際に活用できている割合とは区別する。
7項目の値や仕事例の重なりは能力、採用可能性、収入、投資成績の測定ではない。
星座・アスペクトなど出生図全体の評価でもない。

## 仕事の例

14の職種・役割例に、それぞれ2〜3項目の固定重みを設定する。
出生図側の7項目の値の加重平均で並べ、上位4件を表示。回答の値と出生図の値を混ぜない。
仕事名・使う持ち味・具体的な役割を添える。最上位例から、無料で小さく試せる行動をひとつ提示。
専門資格の保有や、実務経験・収益性を推定しない。
資産運用の選択でも、情報や条件の理解と管理の傾向を扱い、投資商品や売買を勧めない。

## API・互換性

- `POST /api/alignment/result`：計算のみ。専用APIキーもLLM呼び出しも不要。
- 設問画面の読み込み時に `/ready` をバックグラウンドで呼び、テスト用サーバーが休止中なら回答中に起動を促す。失敗しても回答を妨げない。
- `question_version: work-style-3` と24問の正規回答を必須にする。
- `/questions` と `/analysis` は新設問にも対応し、旧8問は `v1` として互換性を維持。
- 設問バージョンは `work-style-3`、今回の採点バージョンは `separate-profiles-1`、一致度の規則は `profile-distance-1`。新旧の採点ルールを混ぜない。
- AIによる補足後も7項目・職種例は固定計算の値を使用し、文章の解釈を更新する。
- 出生時刻必須、都道府県のみ・東京都初期値という既存の入力仕様を維持。

## 確認

全設問の全選択肢、各項目の反転、全項目未定、6つの希望ルート、乱数固定300組の回答を検証。
一致はLv.99、最大の点差はLv.0、比較の対称性と単調性、未確認の除外、42種×3特徴の分類、左右の採点と分類の独立性を検証。
APIキーがない場合でも即時結果に到達すること、AIを呼ばないことを確認する。
従来の8問と採点・AI検証も回帰確認する。
