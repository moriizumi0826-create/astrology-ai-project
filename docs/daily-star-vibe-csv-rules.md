# 本日の星模様CSV 作成ルール

対象ファイル: `database/M_Daily_Star_Vibe.csv`

## 目的

全ユーザー共通の「本日の星模様」を、出生図を使わないトランジットのみで作成する。
APIや画面で日付ごとの共通説明文として使うため、日ごとの主役イベントを明確にし、過剰な専門情報や背景ノイズは避ける。

## CSV形式

- 列は `Date,Text_Description` の2列のみ。
- `Date` は `YYYY/MM/DD` 形式。
- 同じ日付が既にあれば上書きし、なければ追加する。
- 文字コードは UTF-8。更新後はPythonの `csv.DictReader` で読み取り確認する。
- 追加後は対象日が1件ずつ存在すること、本文に `?` の文字化けが混入していないことを確認する。

## 計算基準

- 対象日は日本時間の日付で扱う。
- Swiss Ephemeris / `swisseph` を使い、対象日のトランジット配置を確認する。
- 少なくとも以下を確認する。
  - 主要天体の正午時点のサインと度数
  - 月のサイン移動
  - 月のボイドタイム
  - 太陽と月の月相: 新月、上弦、満月、下弦
  - 個人天体が関わる主要アスペクトのピーク時刻
  - 太陽、水星、金星、火星のサイン移動
  - 水星など、個人天体の逆行/順行ステーション
  - 木星以遠のサイン移動など、社会的に大きいイベント

## 主役の優先順位

本文の中心に置く優先順位は以下。

1. 新月、上弦、満月、下弦などの月相
2. 太陽・月・水星・金星・火星のサイン移動
3. 水星逆行開始/終了など、個人天体のステーション
4. 月のサインとボイドタイム
5. 月と個人天体、または個人天体同士の主要アスペクト
6. 木星・土星など社会天体のサイン移動や、日全体の背景として強く効く配置

満月・新月は必ず本文の主役にする。単なる月アスペクトの一つとして流さない。

## 社会天体の扱い

- 木星、土星、天王星、海王星、冥王星は基本的に背景として扱う。
- ただし以下は本文に入れてよい。
  - 木星や土星のサイン移動
  - 個人天体と正確な主要アスペクトを作る場合
  - 月相やその日の主役テーマを補強する場合
- 「冥王星のみ逆行」など、日々の共通説明として重要度が低い情報は書かない。
- 逆行中というだけの社会天体は、毎回の末尾に機械的に入れない。

## ボイドタイムの扱い

- 月が次のサインに入る前、最後の主要アスペクト後をボイドタイムとして扱う。
- ボイドが日中の大部分を占める場合は本文の主役級として扱う。
- 短いボイドでも、決定や契約を急がないほうがよい時間帯として必要に応じて書く。
- 月相や重要イングレスとボイドが重なる場合は、両方を明記する。

## 文章スタイル

- 1日1件、全ユーザー共通の自然な日本語で書く。
- 出生図、ネイタル、個人別ハウス、個人別アスペクトには触れない。
- 時刻は日本時間で `9:36頃` のように書く。
- 断定的な吉凶ではなく、「向いています」「注意が必要です」「整えると安定します」のような運用可能な表現にする。
- 主役イベント、午前/午後/夜の流れ、昨日や前日からの切り替わりを必要に応じて入れる。
- 専門用語だけで終わらせず、日常でどう使えるかを書く。

## 文章に入れる観点

- 月のサインが示す日中のムード
- ボイド中の注意: 大きな決定より確認、整理、保留
- 月相の意味: 新月は種まき、上弦は調整/行動、満月は結果/可視化、下弦は削ぎ落とし/整理
- 水星: 連絡、言葉、情報、学び、移動、書類
- 金星: 好意、楽しみ、対人距離、美意識、お金の使い方
- 火星: 行動力、焦り、突破力、衝突しやすさ
- 太陽: 季節の切り替わり、意識の中心テーマ

## 避けること

- 出生図を前提にした文。
- 「あなたの○ハウス」など個人チャート依存の文。
- 社会天体の逆行状態だけを毎日機械的に書くこと。
- 月相の見落とし。特に満月・新月は最優先で確認する。
- ボイド中なのに「大きく決める」「契約を進める」といった表現を主推奨にすること。
- CSV更新時にPowerShellの文字コード都合で日本語を `?` に化けさせること。

## 更新手順

1. `database/M_Daily_Star_Vibe.csv` をUTF-8で読み、対象日が既にあるか確認する。
2. `swisseph` で対象日ごとの配置、月相、月サイン移動、ボイド、主要アスペクトを抽出する。
3. 月相専用チェックを行い、新月・上弦・満月・下弦を本文に反映する。
4. 1日1文書として `Text_Description` を作成する。
5. CSVへ追加または上書きする。
6. Pythonの `csv.DictReader` で再読込し、対象日が1件ずつ、本文が空でなく、`?` 混入がないことを確認する。
7. automation memory に、追加した日付範囲、主なイベント、検証結果を短く残す。
8. 依頼がある場合のみ、`database/M_Daily_Star_Vibe.csv` だけをステージしてコミット/pushする。

## 検証例

```powershell
@'
import csv
from pathlib import Path

p = Path("database/M_Daily_Star_Vibe.csv")
with p.open("r", encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))

for d in ["2026/07/02", "2026/07/03"]:
    matches = [r for r in rows if r["Date"] == d]
    text = matches[0]["Text_Description"] if matches else ""
    print(d, "count", len(matches), "len", len(text), "qmarks", text.count("?"))
'@ | python -
```
