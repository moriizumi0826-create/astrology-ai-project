# 本日の星模様CSV 作成ルール

対象ファイル: `database/M_Daily_Star_Vibe.csv`

## 目的

全ユーザー共通の「本日の星模様」を、出生図を使わないトランジットのみで作成する。
APIや画面で日付ごとの共通説明文として使うため、日ごとの主役イベントを明確にし、過剰な専門情報や背景ノイズは避ける。

## CSV形式

- 列は `Date,Text_Description` の2列のみ。
- `Date` は `YYYY/MM/DD` 形式。
- 同じ日付が既にあれば上書きし、なければ追加する。
- 文字コードは UTF-8。更新後はPythonの `csv.DictReader` で読み取り確認する。
- 追加後は対象日が1件ずつ存在すること、本文に `?` の文字化けが混入していないことを確認する。

## 計算基準

- 対象日は日本時間の日付で扱う。
- Swiss Ephemeris / `swisseph` を使い、対象日のトランジット配置を確認する。
- 少なくとも以下を確認する。
  - 主要天体の正午時点のサインと度数
  - 月のサイン移動
  - 月のボイドタイム
  - 太陽と月の月相: 新月、上弦、満月、下弦
  - 個人天体が関わる主要アスペクトのピーク時刻
  - 太陽、水星、金星、火星のサイン移動
  - 水星など、個人天体の逆行/順行ステーション
  - 木星以遠のサイン移動など、社会的に大きいイベント

## 主役の優先順位

本文の中心に置く優先順位は以下。

1. 新月、上弦、満月、下弦などの月相
2. 太陽・月・水星・金星・火星のサイン移動
3. 水星逆行開始/終了など、個人天体のステーション
4. 月のサインとボイドタイム
5. 月と個人天体、または個人天体同士の主要アスペクト
6. 木星・土星など社会天体のサイン移動や、日全体の背景として強く効く配置

満月・新月は必ず本文の主役にする。単なる月アスペクトの一つとして流さない。

太陽・月・水星・金星・火星については、サイン移動がある日だけでなく、滞在中のサインが世の中全体の関心、会話、対人関係、行動傾向へどのようなムードを作っているかも簡潔に説明する。

## 社会天体の扱い

- 木星、土星、天王星、海王星、冥王星は基本的に背景として扱う。
- ただし以下は本文に入れてよい。
  - 木星や土星のサイン移動
  - 個人天体と正確な主要アスペクトを作る場合
  - 月相やその日の主役テーマを補強する場合
- 「冥王星のみ逆行」など、日々の共通説明として重要度が低い情報は書かない。
- 逆行中というだけの社会天体は、毎回の末尾に機械的に入れない。

## ボイドタイムの扱い

- 月が次のサインに入る前、最後の主要アスペクト後をボイドタイムとして扱う。
- ボイドが日中の大部分を占める場合は本文の主役級として扱う。
- 短いボイドは、一日の流れを理解するのに役立つ場合に触れる。決定や契約への注意を毎回添えず、その前後で気持ちや関心がどう切り替わるかを描ける場合は、そちらを中心に書く。
- 月相や重要イングレスとボイドが重なる場合は、両方を明記する。

## 文章スタイル

- 1日1件、全ユーザー共通の自然な日本語で書く。
- 出生図、ネイタル、個人別ハウス、個人別アスペクトには触れない。
- 時刻は日本時間で `9:36頃` のように書く。
- 主役の配置で、どの天体・サインがどう関わり、どんな感じ方や見方の変化が生まれそうかを掘り下げる。月相の一般論やサインのキーワードを並べるだけで済ませない。
- 時刻、前日との差、朝から夜への変化は、主役の配置を理解するのに役立つものを選ぶ。計算で確認したイベントをすべて本文に列挙する必要はない。
- 個人天体のサイン滞在が数日から数週間かけて作る関心や傾向は、その日の読みにつながるものを選び、背景として短く織り込む。
- 仕事、段取り、返事、契約に話を寄せすぎない。その日の配置に合う場面を、気持ちの揺れ、記憶、人との会話、読書や趣味、身近な暮らしなどから選ぶ。状況や気づきが伝わる自然な日本語で書き、断定的な吉凶や決まりきった助言は避ける。
- 結びでは、その日の配置や時間の流れを経て、何の見え方が変わるのか、どんな気づきが残りそうかまで少し詳しく描く。直前の説明の言い直しや、毎日の行動指示で締めくくる書き方は避ける。
- 「世の中のムードは」「今日全体のムードは」のように内部構成をそのまま見出し化した定型句は本文で使わない。
- 「〜を一つ選ぶ」「〜を一つ試す」のように、数を絞らせる定型句で文章を締めない。「一つ」を別の言葉に置き換えて同じ助言を繰り返すことも避ける。

### 読みを深める例

2026/11/24の双子座満月では、射手座の太陽が経験を大きな流れとして捉えようとする一方、双子座の月はそこからこぼれた言葉や細部を拾う。その対比から、別の人の話を聞いて昔の出来事の見え方が変わる、読み返した本の以前は気に留めなかった一節が残る、といった身近な変化を描ける。夜遅くの満月は、日中の牡牛座の月から、気になっていたことに言葉が見つかる夜への変化につなげる。

### アスペクトの角度と意味

- 本文で取り上げるアスペクトは、どの天体同士が何度の角度を取るのかを示す。サインが読みを具体的にする場合は、天体名と一緒に書く。
- 「月と金星が緊張します」のような表現や、角度だけの説明で終えない。その角度が示す重なり、調和、食い違いなどを、同じ文か直後の文で、その日の気持ちや場面につなげる。
- 配置を示したあとに「蟹座の月は〜、天秤座の金星は〜」と天体やサインを個別に説明し直さない。すでに示した配置の意味は、読者が思い浮かべられる場面の中で伝える。
- 例: 14:40頃、蟹座の月と天秤座の金星が、気持ちにずれが出やすい90度の角度（スクエア）を取ります。親しい人と一緒にいたいのに、楽しませようと気を回すうちに、かえってくつろげなくなることも。

## 文章に入れる観点

- 月のサインが示す日中のムード
- ボイドの前後で変わる、気持ちや関心の向き
- 月相とサインの組み合わせから見える、その日のテーマ
- 水星: 言葉の受け取り方、会話、好奇心、情報、学び
- 金星: 好意、楽しみ、対人距離、美意識、お金の使い方
- 火星: 行動力、焦り、突破力、衝突しやすさ
- 太陽: 季節の切り替わり、意識の中心テーマ
- 個人天体のサイン滞在: 世の中全体の会話、好み、行動、関心の向かいやすい方向
- 一日の結びで描く、その日の配置から生まれる気づきや見え方の変化

## 避けること

- 出生図を前提にした文。
- 「あなたの○ハウス」など個人チャート依存の文。
- 社会天体の逆行状態だけを毎日機械的に書くこと。
- 月相の見落とし。特に満月・新月は最優先で確認する。
- ボイド中なのに「大きく決める」「契約を進める」といった表現を主推奨にすること。
- CSV更新時にPowerShellの文字コード都合で日本語を `?` に化けさせること。

## 更新手順

1. `database/M_Daily_Star_Vibe.csv` をUTF-8で読み、対象日が既にあるか確認する。
2. `swisseph` で対象日ごとの配置、月相、月サイン移動、ボイド、主要アスペクトを抽出する。
3. 月相専用チェックを行い、新月・上弦・満月・下弦を本文に反映する。
4. 個人天体のサイン移動とサイン滞在が作る世の中全体のムードを確認する。
5. 主役の配置を掘り下げ、時間帯の変化とサイン滞在の背景を必要に応じて織り込み、日ごとの `Text_Description` を作成する。
6. CSVへ入れる前に本文を通して読み、日付や天体名を変えても通じるような汎用文になっていないか、時刻の列挙で主役が埋もれていないかを確認する。取り上げたアスペクトは、天体名と角度がその日の具体的な意味につながっているか、同じ説明を繰り返していないかも確認する。複数日分を並べて、仕事や段取りへの偏りと、結びの定型句や同じ助言の言い換えを見直す。
7. CSVへ追加または上書きする。
8. Pythonの `csv.DictReader` で再読込し、対象日が1件ずつ、本文が空でなく、`?` 混入がないことを確認する。
9. automation memory に、追加した日付範囲、主なイベント、検証結果を短く残す。
10. 依頼がある場合のみ、`database/M_Daily_Star_Vibe.csv` だけをステージしてコミット/pushする。

## 検証例

```powershell
@'
import csv
from pathlib import Path

p = Path("database/M_Daily_Star_Vibe.csv")
with p.open("r", encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))

for d in ["2026/07/02", "2026/07/03"]:
    matches = [r for r in rows if r["Date"] == d]
    text = matches[0]["Text_Description"] if matches else ""
    print(d, "count", len(matches), "len", len(text), "qmarks", text.count("?"))
'@ | python -
```
