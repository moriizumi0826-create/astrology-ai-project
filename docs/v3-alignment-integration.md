# V3 LPの働き方・資質比較ツール

## 導線

`/entry.html` の「試してみる」から `/alignment.html` へ進む。
ログイン・会員登録・課金とは独立した匿名の体験。戻るリンクはLPへ戻す。
24問 → 出生時刻必須・都道府県選択 → 即時結果。任意で金運AIへ深掘りできる。
回答と出生図の2列、虹色の一致度ゲージ、42種類の名称と3種類の特徴をV1完成版から移植した。
採点詳細は `alignment-work-style-v3.md` を参照。

## API

`backend/v3/alignment.py` が `/api/v3/alignment/ready|chart|result|questions|analysis` を登録する。
旧アプリ全体や `/api/alignment/*` はV3へマウントしない。
既存の会員・決済・ホロスコープ・3Dマップチャットの権限処理は変更しない。
V3の既存オリジン検証とIP判定を使う。出生データや回答を新たに保存する処理は追加していない。

- 計算：匿名の接続元ごとに毎分12回・毎時120回。
- 金運AI：接続元ごとに毎分6回・毎時12回。加えて全体毎時60回・同時3件。
- 即時採点と準備用のreadyはAIキー不要。キー未設定時も結果は使える。

## 専用設定

公開V3バックエンドには `MONEY_AI_API_KEY` と `MONEY_AI_MODEL` を設定する。
モデル初期値はV1と同じ `gpt-6.1-sol`。
既存の `OPENAI_API_KEY` や3Dマップ用キーへ自動で切り替えない。
ローカルではGit対象外の `.env.money-ai` を使用する。`.env.money-ai.example` は空の雛形。
本番への環境変数設定・配備は、この移植作業では実行していない。

## フロントエンド

接続先はV3の `api-origin.mjs` と `VITE_V3_API_BASE_URL` を使用する。
試用ページから認証セッションを要求せず、専用パスのみをV3名前空間へ変換する。
設問JSONをフロントとサーバーで共有。Viteの開発用ファイル許可は、そのJSONファイルだけを追加する。
依存パッケージの追加は不要。
