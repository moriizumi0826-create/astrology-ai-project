# V3 カレンダーメモ

## 仕様

- 1アカウント100件まで、本文1,000 Unicode文字まで。日付付き。画像・添付ファイルなし。
- 有料・招待・確認用会員：作成・編集・閲覧・削除。
- 有料期間終了後：自動削除せず、閲覧・削除のみ。再契約後に編集を再開できる。
- アカウントそのものの削除時はメモも削除（外部キーCASCADE）。出生情報のみの削除ではメモは残る。
- AI回答を選び、日付と本文を編集して保存。1,000文字超の回答は自動切り捨てせず、編集を求める。
- Horoscopeから既存の天体イベントカレンダーをオーバーレイ表示。マップ・チャットをアンマウントしない。
- 星の見通しとHoroscopeは同じカレンダーコンポーネント・同じメモ状態を利用。
- アカウントに保存する情報は日付・本文。個人イベントはアカウントの出生情報で取得し、別人の試算結果と混同しない。
- 固定回答の保存でもAIは呼ばない。

## 安全性と保存

`backend/v3/sql/008_calendar_notes.sql`をV3専用Supabaseへ適用する。
一般会員のDB直接書き込みは禁止し、FastAPIで有料権限を検証した後、サーバー専用RPCで保存する。
読み取り・削除は本人JWTとRLSで本人分のみ。クライアントから所有者IDを受け取らない。
各ユーザーに1〜100の保存スロットを割り当て、UNIQUE制約とアカウント単位の行ロックで同時保存時も100件以下を保証する。
更新にはrevision一致が必要。不一致は409で既存内容を上書きしない。
最大100件を一度に取得し、日付ごとに表示。将来上限を増やす場合は月別取得も検討する。
