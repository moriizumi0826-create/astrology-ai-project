# V3：知人限定のURL共有による試験運用

決定日：2026-09-28

## 今回の到達点

- サイトは既に稼働中。URLを運営者が知人へ個別に共有し、実際の利用で見つかった不具合を順次修正する。
- 一般向けの告知は行わない。新規課金スイッチ`V3_BILLING_ENABLED=false`は維持し、知人はまず無料版を利用する。有料申込を開放する場合は別途判断する。
- これまでに確認済みの登録・無料／有料表示・限定実決済・Webhook・監視を繰り返し検証しない。

## URL共有前に行う最小作業

1. 今回のV3回数制限を、他の未コミット変更と分離してpushする。
2. デプロイ成否だけ確認する。意図的な429発生、本番の再生・決済・障害の再試験はしない。
3. 運営者が知人へURLと「試験運用中。不具合があれば画面・操作・時刻を知らせてほしい」という案内を送る。パスワード・出生情報の全文は報告に含めてもらわない。

## 試験運用中の対応

- 利用者からの不具合を優先度順に修正する。決済・ログイン不可、他人の情報が見える、秘密情報の露出が疑われる場合は通常の表示不具合より先に対処する。
- [運用手順](v3-operations-runbook.md)に従い、既存のBetter Stack通知と問い合わせを確認する。
- 本番での総合テスト、負荷試験、障害訓練、隔離DB復元、海外端末・期限切れなどの細部確認は、今回のURL共有の開始条件にしない。必要になった時点で実施する。
- Supabaseの会員照会がRenderの接続元IP単位で認証制限に達し得る点は、利用者増加前に優先して見直す。現時点では実障害を観測していない。

一般告知や一般向け有料申込は、この試験運用とは別の判断とする。[本番移行フロー](v3-production-launch-flow.md)の「公開完了条件」は一般公開向けの確認項目として残す。
