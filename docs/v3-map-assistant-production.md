# V3 AIガイドの本番設定

- 自由入力：有効な有料会員・招待会員・所有者確認アカウントのみ。API側でも権限を検証する。
- 固定質問：全員利用可能。画面内の固定回答を返し、APIを呼ばない。会員が同じ質問をAPIへ直接送った場合もOpenAIを呼ばない。
- 固定文の共通データ：`frontend/v3/map-assistant-faq.json`。バックエンドも同じファイルを読むためデプロイに含める。

## Render本番APIの環境変数

| 名前 | 設定 |
| --- | --- |
| `OPENAI_API_KEY` | 本番用の秘密キー。Renderの環境変数にのみ保存し、コード・フロントには入れない |
| `V3_MAP_ASSISTANT_MODEL` | `gpt-6-luna`（省略時も同じ） |
| `V3_MAP_ASSISTANT_ENABLED` | `true`で自由入力を有効化。未設定・falseは停止 |

本番ではキー未設定時にデモ回答を返さず、利用不可を表示する。固定質問は停止中でも利用可能。
既存制限は会員ごとに10回/分・60回/時（APIプロセス単位）。入力500文字、履歴最大6件×600文字、出力最大450トークン。全体予算の上限ではない。
送信内容は質問・直近の履歴・マップ表示コンテキスト。出生フォームやメールアドレスは自動送信しない。Responses APIの`store`はfalse。

## 反映時

1. フロントとバックエンドを同じ変更からデプロイする。
2. Renderで上記キーと有効化設定を登録する（キーの内容をチャットに貼らない）。
3. 固定質問の応答と無料会員のロックを確認する。実AIへの試験送信は従量課金が発生する。

停止時は`V3_MAP_ASSISTANT_ENABLED=false`に戻す。課金・招待設定は変更不要。
