# Planet texture sources

These WebP files are generated by `scripts/prepare_planet_textures.py` from official NASA/JPL imagery and models.

- Sun: NASA Solar Dynamics Observatory, AIA 304 Å full-disk image.
- Moon: NASA Scientific Visualization Studio CGI Moon Kit, LRO/LROC global color map.
- Mercury, Venus, Jupiter, Saturn, Uranus, Neptune and Pluto: NASA 3D Resources planet models. The texture data is derived from NASA/JPL mission imagery; Saturn's ring texture is also extracted from the official Saturn model.
- Earth and clouds: NASA Earth Observatory Blue Marble layers.
- Mars: NASA/JPL/Caltech 3D Resources map produced from Viking/USGS imagery.

The Sun texture mirrors the observed hemisphere onto the unseen side. Gas-giant imagery is a static global composite and does not represent the atmosphere at the currently selected date.
